# StockSmart

Static landing page for cPanel / UAE hosting. Upload the whole folder into `public_html` (or a subdomain folder).

## Files

- `index.html`
- `styles.css`
- `script.js`
- `assets/hero.jpg`
- `assets/logo-hole.png`
- `assets/logo-mask.png`

Change the contact address in `index.html` (`mailto:hello@stocksmart.com`) when you have the live inbox or booking link.
